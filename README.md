# 🛒 Simple Amazon Console Application (Java)

## 📌 Project Overview
This project is a simple console-based Amazon application developed in Java to demonstrate important Object-Oriented Programming (OOP) concepts.

The main focus of this project is:
- Constructor Overloading
- Method Overloading

It simulates a basic Amazon shopping flow where products can be created and displayed using different constructors and methods.

---

## 🎯 Features
- Demonstrates Constructor Overloading
- Demonstrates Method Overloading
- Basic product creation
- Console-based user interaction
- Beginner-friendly OOP project

---

## 🧠 OOP Concepts Used
- Classes & Objects
- Constructor Overloading
- Method Overloading
- Encapsulation (basic)
